# Мои финансы

Личный трекер доходов и расходов. Все записи хранятся локально в браузере (`localStorage`): приложение не отправляет финансовые данные на сервер.

## Что есть

- Добавление доходов и расходов в рублях
- Категории, заметки и дата операции
- Баланс, доходы и расходы за выбранный месяц
- График распределения расходов и последние операции
- Фильтры по периоду, типу и категории
- Экспорт резервной копии JSON и восстановление из неё
- Адаптивный интерфейс для телефона и компьютера

## Запуск локально

Откройте `dist/index.html` в браузере или запустите любой статический HTTP-сервер из корня проекта.

## Важно

Это первая локальная версия. Чтобы видеть общие данные на нескольких устройствах, позже понадобится добавить авторизацию и защищённую синхронизацию.
